Privacy policy

Homestead · last updated 15 September 2026

Homestead is a personal, self-hosted assistant used by the two people in one household. It is not a commercial service and has no users beyond the people who linked their own accounts to it.

What it accesses

With the explicit consent of the account holder, and only for accounts that have granted it:

  • Gmail (gmail.modify, gmail.settings.basic) — message headers and bodies, so it can summarise and answer questions about mail; labels and archive state, so it can file what has been handled; and mail filters, which it may only create after a person approves each one. It is not granted permission to send mail.
  • Google Calendar (calendar.readonly) — event times, titles and attendees, read-only.
  • Google Tasks (tasks) — a single list it creates and maintains, mirroring the household's own chores and to-dos.

Where the data goes

To a server in my home and nowhere else. There is no hosted backend, no analytics, and no third-party service that receives your mail, calendar or tasks. Backups are encrypted and held in storage I control.

Text is sent to a large language model provider when — and only when — a person asks the assistant something that requires it. That may include the content of a message being summarised. No Google user data is used to train any model by Homestead itself.

What it is never used for

Google user data obtained through these scopes is never sold, never shared with anyone outside the household, never used for advertising, and never used to train a model.

Limited Use

Homestead's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and removal

Mail and calendar data are read as needed and are not kept beyond what the assistant needs to answer with; notes a person asks it to keep are stored in a private vault on the same server. Revoking access at myaccount.google.com/permissions stops all access immediately. To have the stored data deleted as well, email the address below and it will be removed.
