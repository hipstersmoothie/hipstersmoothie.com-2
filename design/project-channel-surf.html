How it’s built

A native tvOS app, with an MCP server inside.

Everything runs on the Apple TV. There’s nothing to install on the server, and nothing on it changes. Turn on Agent Access and Claude Code can program your channels over the home network.

  • Swift · SwiftUItvOS 26, focus engine, Top Shelf
  • Plex · Jellyfin · EmbyDirect to the server’s API; no middle tier
  • SchedulesDeterministic shuffles so every device agrees on what’s on
  • MCPAn in-app server; QR code pairs an agent
  • StoreKit 23-day trial as a free non-consumable, then one unlock
  • XcodeGenproject.yml → .xcodeproj; devicectl installs

Why I made it

I wanted to stop choosing.

We had a Plex library we never watched. Opening it meant twenty minutes of scrolling and then a rewatch of the same three things. What I actually missed was flipping channels: landing on something halfway through and staying.

Channel Surf started as a weekend tvOS experiment and became the first thing I shipped to the App Store. The hard parts were the ones you can’t see: schedules that agree across devices without a server, a guide that feels native to the Siri Remote, and a trial that passes App Review.

Version 1.3 added your own channels, rules that keep up with your library, and an MCP server so you can just ask an agent for “a Saturday morning cartoons channel.”
